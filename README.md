# Default_Plus UI for EverQuest Legends!

Default_Plus is mainly an edit of the default UI but with some features from default_modern. I wanted to share the modifications in-case there were other users out there that wanted to use it.

## Installation

I did not want to include Daybreak/GameJawn's files in here because I'm sure they'd have come after me. SO this is how it's going to have to be installed.

### Step 1:

Copy your default ui skin located where you installed the game. The default location is:
```
C:\Users\Public\Daybreak Game Company\Installed Games\EverQuest Legends\uifiles\
```

### Step 2:

Create a new folder within uifiles and name it default_plus
<img width="819" height="288" alt="image" src="https://github.com/user-attachments/assets/7fe4938a-7118-4acb-a57d-ec7a57fbec88" />


### Step 3:

Paste the contents of default folder into the default_plus folder
<img width="840" height="607" alt="image" src="https://github.com/user-attachments/assets/52b544d6-615a-4fb2-b959-932938cb6e8e" />


### Step 4:

Download the default_plus zip folder and paste the XML docs into the folder.
<img width="861" height="611" alt="image" src="https://github.com/user-attachments/assets/bc247715-f781-4709-b50f-6a34520078f5" />


### Step 5:

If you had your game open, type
```
/loadskin default_plus
```
to load the UI.
